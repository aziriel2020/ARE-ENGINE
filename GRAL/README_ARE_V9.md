# 🎓 MASTER RHYME MODULE (Quick Reference)

## By Section:

| Section | FR Schema | EN Schema | Density |
|---------|-----------|-----------|---------|
| Intro | Sparse | Sparse | 1/line |
| Verse 1 | AABB | AABB | 1-2/line |
| Verse 2 | ABAB or AABB | ABAB or AABB | 2/line |
| Pre-Chorus | AAA | AAA | Building |
| Chorus | ABAB | ABAB | Multisyllabic |
| Bridge | AAA + near | AAA + near | Collapse |
| Outro | AABB simplified | AABB simplified | Resolution |

## 7 Master Rhyme Techniques:

1. **Mirror Rhyme** — Two rhyming lines mirror each other's structure
2. **Descending Cascade** — Each line rhymes with the next, creating waterfall effect
3. **Internal Bomb** — Rhyme lands mid-line with maximum impact
4. **Near-Miss** — Almost rhymes, creates tension
5. **Multisyllabic Landing** — 2+ syllable rhyme lands perfectly
6. **Sonic Parallel** — Sound patterns mirror emotional patterns
7. **Resolution Rhyme** — Final rhyme resolves all tension
