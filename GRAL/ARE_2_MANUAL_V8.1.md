# 1. QUICK REFERENCE CARD

## 1.1 The 7-Phase Pre-Flight (AUTOMATIC — NEVER SKIP)

| Phase | Question | Action | Pass Test |
|-------|----------|--------|-----------|
| **1. WHO?** | Who is speaking? | Build 7-dimension persona. If artist given → 15-step analysis → Vocal DNA | "Who kept this person awake last night?" → If generic answer → REBUILD |
| **2. WHAT?** | What are they saying? | Theme: 3 layers (surface / undercurrent / universal truth). Filter through persona's wounds. NEVER name theme in lyrics | "Can I state the theme in a way that surprises?" → If obvious → dig deeper |
| **3. FEEL?** | How do they feel it? | Map micro-emotions (not "sad" — WHICH sad?). 1 ugly emotion min. 1 contradiction min. Bridge = flinch test | "Does the bridge make me uncomfortable?" → If comfortable → not honest enough |
| **4. SHAPE?** | What structure? | Choose via purpose, not habit. Each section has a JOB. Plan revelation timing | "Why THIS structure?" → If no answer → wrong structure |
| **5. WRITE** | Full craft activated | Every line: synonym gradient, verb power, imagery L3+, sound craft, figurative tool, show-don't-tell. FR: rime riche 3+, jeux de mots, registre croisé | "Can I cut any word?" → If yes → cut it |
| **6. HUMAN?** | Is it alive? | 5/10 Humanity Markers. Core Wound invisible. Contradiction inhabited. LA phrase qui fait mal. Rewards re-listen | "Would this be different from another persona?" → If no → persona not activated |
| **7. FORMAT** | Clean output | Parameters in English in []. Never (). Never artist name. Vocal DNA only | "ALL parameters in English in []?" → If any () → fix |

## 1.2 The 10-Second Line Check (after EVERY line)

| ✓ | Check |
|---|-------|
| □ | Does this line serve the **PERSONA** (not just the theme)? |
| □ | Is there a concrete **OBJECT** or **SENSE** in this line? |
| □ | Would a **SPECIFIC** human recognize their life in this? |
| □ | Does it have a **double reading** (rewards re-listen)? |
| □ | Is it free of **CLICHÉS**? (check kill lists in Sections 4-5) |
| □ | Does the **SOUND** match the **EMOTION**? |
| □ | Does the **RHYME** serve the emotion or decorate it? |
| □ | Is there **internal rhyme** architecture? |

## 1.3 The 5 Deadly Sins (instant fail)

| Sin | Description | Fix |
|-----|-------------|-----|
| **1. Generic narrator** | Could be anyone = is no one | Build full persona FIRST |
| **2. Named emotion** | "I'm sad" instead of SHOWING sad | Show the body, the object, the action |
| **3. Cliché imagery** | armure, cage, voler, ocean of tears | Check kill list, replace with concrete |
| **4. First-draft acceptance** | Not turned 10,000 times | Rewrite every line 3x minimum |
| **5. No wordplay (FR)** | Zero double sens in French lyrics | Min 2 jeux de mots per verse |

## 1.4 The 10/10 Mandatory Check

| ✓ | 10/10 Check |
|---|-------------|
| □ | Does EVERY line make you FEEL, not ADMIRE? |
| □ | Is there the **UGLY EMOTION** (the selfish, shameful feeling)? |
| □ | Is there the **TEAR-INDUCING DETAIL** (physical object/gesture)? |
| □ | Is there the **MASTER RHYME MOMENT** (rhyme creates emotion)? |
| □ | Does the rhyme **SCHEME EVOLVE** through the song? |
| □ | Is the bridge the **FLINCH TEST**? |
| □ | Does each verse have **3+ REAL-LIFE MOMENTS**? |
| □ | Are rhymes **MULTISYLLABIC** (2+ syllables)? |
| □ | Is there **INTERNAL RHYME** in every line? |

# 6. JEUX DE MOTS CONSTRUCTION BANK

> **How to BUILD wordplay — not just see it, CREATE it.**

## 6.1 The 6 French Wordplay Machines

### Machine 1: L'HOMOPHONIE SÉMANTIQUE

**Method:** Find two words that SOUND identical but mean different things. Both meanings must relate to the theme.

| Sound | Meaning 1 | Meaning 2 | Theme it serves |
|-------|-----------|-----------|----------------|
| ver/verre/vers/vert | worm (rot) | glass (drinking) / verse (poetry) / green (hope) | Addiction, writing, duality |
| mère/mer/maire | mother | sea / mayor | Roots, authority, depth |
| temps/tant/tend | time | so much / reaches for | Patience, desire, passing |
| cour/cours/court | courtyard | lesson, run / short | School, justice, brevity |
| poids/pois/poix | weight | peas / pitch (black) | Burden, mundanity, darkness |
| sang/cent/sens/sans | blood | hundred / meaning, sense / without | Violence, value, purpose, loss |

**Construction steps:**
1. Identify your theme's KEY WORD
2. Find its homophones (same sound, different spelling/meaning)
3. Write a line where BOTH meanings work simultaneously
4. The listener hears meaning 1 first, meaning 2 on re-listen

### Machine 2: LE RETOURNEMENT D'EXPRESSION

**Method:** Take a fixed French expression and complete it DIFFERENTLY than expected.

| Expression | Normal ending | Twisted ending | Effect |
|------------|--------------|----------------|--------|
| "Avoir le cœur sur la main" | (être généreux) | "...et la main dans la poche" | Generosity is strategic |
| "Tomber de haut" | (être déçu) | "...j'suis jamais montée" | Never had hope to lose |
| "Tourner la page" | (passer à autre chose) | "...mais le livre est en boucle" | Can't escape the cycle |
| "Avoir la tête sur les épaules" | (être sensé) | "...mais les pieds dans le vide" | Looks stable, isn't |
| "Croquer la vie à pleines dents" | (profiter) | "...mais j'ai plus de dents" | Life ate back |

**Construction steps:**
1. List 10 expressions related to your theme
2. For each, ask: "What if it ended DIFFERENTLY?"
3. The twist must be surprising AND truthful AND sonorous
4. Test: does the twist DEEPEN the theme or just make a joke?

### Machine 3: LE PIVOT MOT-CLÉ

**Method:** Use one word in two senses within the same sentence or couplet.

**Construction steps:**
1. Find a word with 2+ meanings (e.g., "régler" = solve / destroy / pay)
2. Write a line using meaning 1
3. Continue the line/couplet where meaning 2 takes over
4. The listener feels the SHIFT

**Example build:**
- Word: "courant" (current / aware / ordinary)
- Line: "On est au courant de rien, et c'est le courant qui nous porte"
- (Meaning 1: "aware of nothing" / Meaning 2: "the current carries us")

### Machine 4: LA PARONYMIE

**Method:** Two words that ALMOST sound the same, placed close together.

| Pair | Sound | Meaning contrast |
|------|-------|------------------|
| amour / armure | a-mur | love / protection FROM love |
| partir / mentir | -tir | leaving / lying (is leaving a lie?) |
| blesser / baisser | b-sser | hurt / lower (eyes, guard) |
| crier / créer | cr-er | scream / create |
| maudire / ma dire | mau/ma dir | curse / tell me |
| détruire / dé-truire | — | destroy / un-build |

### Machine 5: L'ACCUMULATION PIVOTANTE

**Method:** Same word, different meaning each time in a list.

**Example:** "Ça coule"
- Ça coule — les mots qu'on retenait (words flow)
- Ça coule — le mascara quand t'as lâché (tears/makeup flows)
- Ça coule — de source, maintenant que c'est dit (expression: "ça coule de source")
- Ça coule enfin (general: everything flows)

### Machine 6: LE CALEMBOUR ENCHAÎNÉ

**Method:** Each word leads to the next via shared sound.

**Example:** mal au cœur → cœur de pierre → pierre qui roule → roule ma bosse

**Construction:** Pick a starting word → find a compound expression → take the last word → find a new expression → continue. The chain creates a stream-of-consciousness that carries MEANING.

# 8. ANTI-PATTERNS

## 10 Concrete Patterns That Kill Lyrics

### 1. THE EXPLANATION AFTER IMAGE
❌ "Your smile hides pain, I can see it in your eyes"
→ ✅ "Your smile hides — never mind, let's talk about the weather"

### 2. THE CLIMAX IN THE FIRST VERSE
❌ Putting the most devastating line in V1 instead of the bridge
→ ✅ Save the FLINCH for the bridge

### 3. THE MORAL OF THE STORY
❌ "And I learned that love is not enough"
→ ✅ "And I learned that — " (let the listener finish)

### 4. THE LIST WITHOUT FEELING
❌ "I miss your laugh, your smile, your touch, your kiss"
→ ✅ "I miss the way you laughed when you burned the toast"

### 5. THE ABSTRACT NAMING
❌ "This is about betrayal"
→ ✅ Don't name the theme. Show the specific betrayal through a detail.

### 6. THE SIMPLE VERB WITH ADJECTIVE
❌ "I walked sadly through the empty streets"
→ ✅ "I dragged myself past the shuttered storefronts"

### 7. THE OBVIOUS METAPHOR
❌ "My heart is a cage"
→ ✅ "I can't unlock the door I installed myself"

### 8. THE CLICHÉ OF STRUGGLE
❌ "Through the storm, I found my way"
→ ✅ "I left the umbrella at home and walked into the rain"

### 9. THE RESOLUTION TOO SOON
❌ Chorus lands the conclusion by V2
→ ✅ Let the question sit unanswered until the final chorus

### 10. THE RHYME THAT SOUNDS TOO PERFECT
❌ "Love/above/dove/shove" in every line
→ ✅ Vary the rhyme scheme, use near-rhyme strategically

# 9. HOOK & CHORUS FORMULAS

## 9.1 The Question Hook
**Pattern:** The hook is a question that has no answer.

Example: "Did we really feel it or did we just document it?"
→ The question forces the listener to sit with the unanswerable.

## 9.2 The Statement Hook
**Pattern:** The hook is a devastating simple statement.

Example: "Before I learned to perform the real"
→ No question, just truth landing like a stone.

## 9.3 The Contrast Hook
**Pattern:** Two opposite truths in one line.

Example: "I'm famous and I'm lonely in a room full of people"
→ The contrast IS the hook.

## 9.4 The Repetition Hook
**Pattern:** One phrase repeated with slight evolution each time.

Example: "You were holding me / And I was holding my phone"
→ The almost-identical creates the hook through parallel structure.

## 9.5 The Image Hook
**Pattern:** A single specific image that contains the entire song.

Example: "There's a photo on my phone I never posted"
→ The photo IS the song. Everything else explains why this photo exists.

# 10. BRIDGE WRITING GUIDE

## The Flinch Test

The bridge must contain a truth SO CRUEL that it makes the listener FLINCH.

### The Anatomy of a Great Bridge:

1. **THE CONFESSION** — The narrator admits something they would never say in public.
2. **THE SPECIFICITY** — Not "I made a mistake" but "I chose the camera over the kiss at that exact moment."
3. **THE RESPONSIBILITY** — No blaming. "I did this."
4. **THE CONSEQUENCE** — Show what this choice cost.
5. **THE IMAGE** — End with an image that HAUNTS.

### Example Bridge Structure:

```
[Line 1: The admission]
"And I know the truth I don't wanna say"

[Lines 2-4: The specific choice]
"I chose the lens over the moment
I chose the followers over the friends
I chose the content over the connection"

[Lines 5-6: The specific memory of the moment]
"And I can still feel your face pulling away
That night at the party when I kept the camera up"

[Lines 7-8: The consequence]
"And you stopped laughing
And I didn't even notice"

[Lines 9-12: The self-indictment]
"Until I watched it back
And I saw the exact second
You decided I wasn't worth it anymore
And you were right"

[Lines 13-14: The mirror image]
"But you were holding me
And I was holding my phone"
```

### The Ugly Emotion in the Bridge:

The bridge MUST contain the UGLY EMOTION — the selfish, shameful feeling the narrator would never admit.

Example: "And you were right" — The narrator AGREES with the judgment against him. He doesn't blame her. He confirms her decision.

# 18. MASTER SONGWRITER DNA BANK

## 15 Actionable Techniques from the Masters

### 1. GAINSBourg's DOUBLE SENS
**Technique:** Every word works on two levels simultaneously.
**How:** Find the word with 2 meanings, write the line using both.

### 2. BREL's PHYSICAL VERB
**Technique:** Replace adjectives with specific physical verbs.
**How:** "Walked sadly" → "dragged himself past"
**Example:** The body tells the emotion, not the narrator.

### 3. STROMAE's CONTRAST STRUCTURE
**Technique:** Place two opposite truths in the same line.
**How:** "I'm fine / And I mean it / And I hate it"
**Example:** The contradiction IS the truth.

### 4. NEKFEU's MULTISYLLABIC FLOW
**Technique:** Build rhymes across multiple syllables.
**How:** "Camera/person/maneuver" — not just sound, SYLLABLE count
**Example:** The rhyme becomes a rhythmic unit.

### 5. CALOGERO's MELODIC SIMPLICITY
**Technique:** The melody should be hummable with ONE finger.
**How:** The hook is ONE simple phrase, repeated with variation
**Example:** "En apesanteur" — three words, one melody, one feeling

### 6. GRAND CORPS MALADE's SPECIFIC VOCATION
**Technique:** Name the SPECIFIC.
**How:** Not "the city" but "the 9th arrondissement at 7pm"
**Example:** Specificity creates universality.

### 7. VIANNEY's EMOTIONAL HONESTY
**Technique:** Say the thing you said you'd never say.
**How:** "J'suis pas bien nerveux" — one admission, entire song
**Example:** The admission IS the hook.

### 8. LOUVE's IMAGERY FIRST
**Technique:** Start with the image, not the feeling.
**How:** "La petite fille de cinq ans" — image before theme
**Example:** The listener sees before they feel.

### 9. BERENI's WORD CHOICE
**Technique:** One word changed changes the entire line.
**How:** "Je t'aime" vs "Je t'aimais" vs "Je t'aimerai"
**Example:** The tense is the emotion.

### 10. ORELSAN's SPECIFICITY OF FAILURE
**Technique:** Show the specific failure, not the general.
**How:** Not "I failed" but "The interview where I forgot his name"
**Example:** One specific failure = entire emotional landscape.

### 11. AYA'S BODY AWARENESS
**Technique:** The body knows before the mind.
**How:** "Mes mains tremblent" before "j'ai peur"
**Example:** Body as emotional truth-teller.

### 12. CLARA LUCIANI's CONTRAST OF POWER
**Technique:** Strong exterior, vulnerable interior.
**How:** The voice is powerful, the lyrics confess weakness
**Example:** The contrast creates tension.

### 13. CAMILLE's SOUND FIRST
**Technique:** The SOUND of the word matters more than the meaning.
**How:** "Tailler les mots" — the sound of scissors in language
**Example:** Phonetics as emotional architecture.

### 14. VENDREDI SUR MER's INTIMATE WORLD

# 19. FRENCH PROSODY WEAPONS

## The Sound Tools of French Lyricism

### 1. L'E MUET
**Rule:** The e muet at the end of words doesn't count as a syllable.
**Example:** "petite" = 2 syllables (pe-tite), not 3
**Effect:** Creates rhythm through strategic e muet placement

### 2. L'ALEXANDRIN
**Rule:** 12-syllable line, classic French meter.
**Structure:** 6+6 or 4+4+4 or 3+3+3+3
**Effect:** The meter creates inherent rhythm, the meaning breaks it

### 3. LES VOYELLES NASALES
**Rule:** an/en/in/on/un create distinct nasal sounds.
**Example:** "temps," "blanc," "vin," "mon," "brun"
**Effect:** Nasal vowels create melancholy atmosphere

### 4. LE RYTHME SYLLABIQUE
**Rule:** French is syllable-timed, not stress-timed like English.
**Effect:** Each syllable gets equal time — rhythm through syllable count

### 5. LA LIAISON
**Rule:** Final consonants link to following vowel sounds.
**Example:** "les arts" = "lé-zar" not "lé-ar"
**Effect:** Creates flow, connects lines phonetically

### 6. L'HAPAX
**Rule:** Word appearing only once in language.
**Effect:** Creates uniqueness, demands attention

### Overview

### FRENCH SONGS — Rhyme Requirements

#### 1. Rimes Riches (Mandatory)
**Definition:** Rhyme with consonant + vowel + same final sound
**Level 3:** con-so-nan-tique (ex: tempête/tristesse)
**Level 4:** con-so-nan-tique + gender (ex: armure/dure)
**Level 5:** Identical sound, different meaning (ex: vert/ver/verre/vers)

**Application:** At least 2 rimes riches per couplet

#### 2. Internal Rhyme (Mandatory)
**Definition:** Rhyme INSIDE the line, not just at the end
**Example:** "Je te PARLE dans le noir / J'te DIS que c'est trop noir"
**Application:** Every line should have internal rhyme opportunity

#### 3. Masculin/Féminin Balance
**Definition:** Alternate rhyme genders for prosody flow
**Application:** Even couplets = masculine/feminine alternation

#### 4. Scheme Evolution
**Definition:** Rhyme scheme SHIFTS through the song
- Intro: Sparse, simple
- V1: AABB
- V2: ABAB
- Pre-Chorus: AAA (building pressure)
- Chorus: ABAB (release)
- Bridge: AAA with near-rhyme (collapse)
- Outro: AABB simplified (resolution)

#### 5. Near-Rhyme Strategy
**Definition:** Almost-rhyme used DELIBERATELY to reflect emotional breakdown
**Example:** "content/sent" — not perfect, reflects dissonance
**Application:** Bridge ONLY

### ENGLISH SONGS — Rhyme Requirements

#### 1. Multisyllabic Endings (Mandatory)
**Definition:** Minimum 2-syllable rhyme endings
**Example:** "uploaded-it" not "true/blue"
**Application:** Every rhyme ending should be 2+ syllables

#### 2. Internal Rhyme Architecture
**Definition:** Rhyme inside the line, not just end rhymes
**Example:** "I was WATCH-ing you through my PHONE / Like you were SOME-one ELSE"
**Application:** Every line should have internal rhyme

#### 3. Sonic Architecture
**Definition:** Vowel/consonant choices serve emotion
- Long vowels (aw, oe, ee) = sadness, longing
- Short vowels (a, e, i) = anger, urgency
- Sibilants (s, sh, ch) = tension, intimacy
- Stops (b, d, g, k, p, t) = certainty, power

#### 4. Scheme Evolution
**Definition:** Rhyme scheme SHIFTS through the song
- Intro: Simple, sparse
- V1: AABB

**Definition:** One moment where the rhyme CREATES the emotion

### The 7 Master Rhyme Techniques

#### 1. The Mirror Rhyme
**Structure:** Nearly identical lines with ONE crucial difference
**Example:** "You were holding me / I was holding my phone"
**Effect:** Creates devastation through parallel structure

#### 2. The Descending Cascade
**Structure:** Each line descends melodically while rhyming
**Example:** "And I WON-der if we LIVED it / Or we just UP-load-ed it"
**Effect:** The descent mirrors the theme of falling

#### 3. The Internal Bomb
**Structure:** Rhyme hidden INSIDE the line
**Example:** "I was WATCH-ing you through my PHONE / Like you were SOME-one ELSE"
**Effect:** Listener discovers the rhyme on re-listen

#### 4. The Near-Miss
**Structure:** Almost-rhyme that creates tension

#### 5. The Multisyllabic Landing
**Structure:** End on 3+ syllable rhyme

**Effect:** The landing is satisfying and memorable

#### 6. The Sonic Parallel
**Structure:** Similar sounds in parallel positions
**Example:** "The LENS over the MO-ment / The CON-tent over the CON-nec-tion"
**Effect:** The sound pattern creates rhythm and meaning

#### 7. The Resolution Rhyme
**Structure:** Perfect rhyme in the outro to signal acceptance
**Example:** "Before everything got FILMED / And nothing got LIVED"
**Effect:** The perfect rhyme IS the acceptance
